# 🍕 Crust

A modern pizza ordering platform built with **React**. Crust provides a clean and responsive interface for browsing pizzas, customizing orders, managing a cart, and placing orders.

> Built as a hands-on project to apply modern React development concepts in a realistic application.

## ✨ Features

- 🍕 Browse available pizzas
- 🛒 Add and remove items from the cart
- ➕ Adjust item quantities
- 🧀 Customize pizza orders
- 📦 Manage the current order
- 📱 Responsive user interface
- ⚡ Fast and interactive React experience

## 🛠️ Tech Stack

- **React**
- **JavaScript**
- **HTML5**
- **CSS3**
- **Redux** for state management
- **Vite** for development and build tooling

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Saadbinzahid1/crust.git
```

### 2. Navigate to the project

```bash
cd crust
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local development URL provided by Vite.
